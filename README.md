# Billiard Space Planner

Internal floor-plan and equipment planning application
for billiard equipment shops.

## Architecture

- Angular frontend
- Spring Boot backend
- PostgreSQL + PostGIS
- JTS geometry engine
- Docker Compose infrastructure

## Requirements

- Java 21
- Node.js 24
- Maven 3.9+
- Docker Desktop

## Start database

```powershell
docker compose up -d database
```
